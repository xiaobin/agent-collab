# 全链路生命周期

适用于需要多步实现、多人或多 agent 协作的任务。小任务可压缩阶段，但不能省略目标、权限和验收。

| 阶段 | 进入条件 | 出口判据 | 主要产物 |
| --- | --- | --- | --- |
| 1. 目标入场 | 有用户指令、PRD、Issue 或任务卡 | 目标、非目标、约束、授权和权威来源明确 | 当前任务卡 |
| 2. 调查与范围基线 | 目标明确 | 受影响模块、文件、接口、数据、页面已枚举；多仓权威源已判断 | 范围清单 |
| 3. 规划与排期 | 基线可用 | 阶段、依赖、写范围、并行条件、风险和验收策略明确 | 计划与波次 |
| 4. 设计与契约 | 规划可用 | 对外接口和兼容约定冻结；高风险设计经预审 | 设计与契约 |
| 5. 环境准备 | 契约可用 | 依赖、测试数据、隔离环境和自检就绪；缺配置已交回用户 | 环境自检 |
| 6. 实现 | 写范围与验收明确 | 正常和异常路径实现，自测通过，diff 未越界 | 代码与自测证据 |
| 7. 协调者验证 | 实现者稳定、结果可取 | 协调者亲自重跑验收，退出码和真实副作用符合预期 | 验证记录 |
| 8. 独立复审 | 技术验证通过 | 独立 reviewer 给出结论；问题已修复或退回实现 | 审查记录 |
| 9. 集成与回归 | 各写范围验收通过 | 冲突清零，全量与固定回归通过，接口一致，回滚可评估 | 集成证据 |
| 10. 提交与推送 | 集成通过且已有明确授权 | 写范围与 secret 扫描通过；未夹带无关修改；不 force push | commit 与推送回执 |
| 11. 发布与数据迁移 | 用户单独授权 | 备份、演练、回滚和逐项生产确认齐备 | 发布或迁移记录 |
| 12. 业务验收 | 技术核验完成 | 范围差集闭环，用户按真实业务链路走查，遗留风险已披露 | 业务验收记录 |
| 13. 收尾与沉淀 | 验收完成 | 本次资源回收，证据保留，技术债和有证据的教训登记 | 收尾与复盘 |

## 回退

- 验证或复审不通过：回到实现，新建修复 Attempt，不覆盖原失败证据。
- 集成冲突：回到集成步骤串行处理，并重新回归。
- 契约需要变化：回到设计，并取得用户确认。
- 回退只退必要的一环，不用“再试一次”掩盖根因。
- 同一缺陷两轮未过，换方案、缩小技术尝试范围或交回用户，不同法重试第三轮。

## 暂停

暂停时留下当前阶段、在飞任务、占用资源、下一动作和恢复第一条命令。无人值守时，不让后台 writer 悬在未知运行态。越权事项停在该阶段之前，不先做再补授权。
